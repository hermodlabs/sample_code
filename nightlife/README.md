# Nightlife

[Street-team deployment](street-team-deployment/README.md) builds an operating
app and a guided workflow through the public CLI, then works one fictional
venue review. It checks staff remaining inside, timing, recorded access and
spending requirements. Its financial explanation gives conditional whole-guest
thresholds without predicting customer response.

The sample includes all editable rules, workflow mappings, scenarios and review
records needed to recreate its package. Decision Lab can install that package
and continue its native case run using the existing guided interface.
